# Web-Dev-Task.

Technical Architecture:

the Website has a Static Frontend with no backend and uses the local storage for the storing of data with the help of JavaScript..

Modules:

There are a total two pages in the website where the first page would get the username of the user and a second main page with the feature to post content on the site..

there are two HTML,CSS,JS documents each for each of the page controlling the structure of the two pages..

the features such as like count, comment, share, profile page are incomplete due the constraint of time..

Tools used:

Google Fonts, images available on the web, some AI to edit the pictures used..

To run the Project:

Go on GitHub open the repo then go on the settings and click the pages button then choose main and /root and press save..it will start launching the website. Which can then be viewed from the link that pops up..
